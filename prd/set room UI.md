set-room
页面作用：上帝在创建房间后进入本页，确认/填写工作坊名称（可跳过），点击“发起”后将房间状态置为已发起，并跳转到下一步页面（Select Mode，已存在）。
入口：主页点击「创建房间」成功后自动跳转到本页，并携带 roomId
3. 本期版本的统一默认策略（新增关键需求）
昵称策略：所有新增玩家（含创建者/上帝）统一使用默认命名规则
创建者进入 set-room 时展示：玩家1
后续加入的玩家依次为：玩家2、玩家3…（编号递增）
本模块允许创建者在 set-room 修改自己的昵称：默认值可被覆盖
仅影响“当前用户在该房间的 displayName”（不影响其他玩家默认命名规则）

头像策略：所有用户头像先统一使用灰底填充默认头像（占位图）
在 set-room 页面允许点击头像：
从相册选择 / 拍摄 更换头像
头像选择后即时预览
若接入上传：上传成功后使用云端 url；失败提示并回滚到默认头像或上一次头像

4. 页面前端布局
4.1 顶部导航区
左上：返回箭头
背景：白色
交互：
点击返回：返回上一页（auth）（wx.navigateBack()）
4.2 标题区（居中）
主标题：发起工作坊
说明文字（两行）：
“设置您的头像、昵称以及工作坊名称”
“便于其他用户找到您”

4.3 头像区（居中大圆）
圆形头像展示（大尺寸）100*100px
显示内容：灰底默认头像（统一占位图）
交互（本期）：
点击头像 → 弹出选择：
从相册选择
拍摄
选择后：
立即更新头像预览（本地路径）
（可选）开始上传并替换为云端头像 URL

4.4 昵称区（头像下方居中）
昵称文本：默认显示 玩家1（创建者）
右侧：绿色编辑图标 assets\icons\editname.png

交互（本期）：
点击昵称或编辑图标：进入编辑状态（不要用弹窗，只是默认昵称变灰输入态，右侧增加icon:assets\icons\comfirm.svg以确认修改）

4.5 工作坊名称输入区（居中输入框）
输入框 placeholder：设置工作坊名称
默认值：脑暴工作坊
右侧清除按钮（×）assets\icons\delete.svg：有内容时显示，点击清空
工作坊名称可跳过-使用默认值
规则：
自动 trim 首尾空格
建议长度：0~20 字（超出可截断或提示）
4.6 底部主按钮（发起）
按钮文案：发起
位置：页面底部居中，宽按钮
默认置灰/可用逻辑：
当 roomId 未获取到或正在提交：置灰不可点
当 roomId 有效且未提交：可点
点击后动作：
提交工作坊配置（至少包含 roomId、workshopName）
将房间状态更新为 STARTED
跳转下一页：/pages/select-mode/index?roomId=xxx
失败处理：
toast：发起失败，请重试
保留已输入的工作坊名称
5. 页面数据与状态
5.1 入参
roomId（必传）：从 query 读取
5.2 页面展示数据（本期）
displayName: 固定为 玩家1（创建者）
avatar: 为灰底默认头像资源或用户修改的图片
workshopName: 用户输入（默认为：‘脑暴工作坊’）
5.3 页面状态
idle：可输入/可发起
submitting：点击发起后请求中（按钮置灰）
6. 与“默认玩家1/2/3 + 默认头像”的实现要求（本页需要配合的点）
6.1 本页对“玩家序号”的要求
创建者进入 set-room 时，需要能得到自己的默认编号 1
因为本期不拉取用户信息，建议在创建房间成功时就完成：
给创建者分配 playerIndex = 1
本页直接展示 玩家${playerIndex}
