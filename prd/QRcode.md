你是一名资深微信小程序开发工程师。

请帮我实现一个“扫码加入”功能，具体需求如下：

业务场景：
用户在 aaa 页面点击“扫码加入”按钮，通过扫描二维码加入某个资源（例如群组、活动或团队）。



交互流程：
1. 用户进入 AAA 页面
2. 页面有一个按钮：扫码加入
3. 用户点击“扫码加入”
4. 调用 wx.scanCode 打开扫码功能
5. 支持扫描二维码
6. 扫码成功后获取二维码内容
7. 将二维码内容作为参数调用后端接口进行加入操作
8. 加入成功提示用户，并刷新页面状态
9. 扫码失败或取消扫码需要提示用户

技术要求：
- 微信小程序原生开发
- 使用 wx.scanCode API
- 使用 JavaScript + WXML + WXSS
- 扫码逻辑写在 AAA 页面 JS 中
