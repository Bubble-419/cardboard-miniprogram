# 云开发配置：邀请成员与房间小程序码

本文说明为「aaa 测试页 → addPlayer 添加成员 → 扫码加入房间」功能所需在微信云开发中进行的配置与操作步骤。

---

## 一、云开发环境确认

1. 在微信开发者工具中打开本项目，确保已开通并选中**云开发**环境。
2. 在项目根目录的 `project.config.json` 或 云开发控制台中确认 **云开发环境 ID**（如 `xxx-xxx`）。

---

## 二、云数据库集合与权限

### 1. 所需集合

| 集合名称     | 说明           |
|-------------|----------------|
| `rooms`     | 房间主表       |
| `roomMembers` | 房间成员表   |

若尚未创建，在 **云开发控制台 → 数据库** 中新建这两个集合。

### 2. rooms 集合字段（建议）

- `roomId`（string）：房间唯一 ID  
- `status`（string）：如 `CREATED` / `STARTED` / `ENDED`  
- `creatorId`（string）：创建者 openid  
- `createdAt`、`updatedAt`（number）：时间戳  
- `clientCreateId`（string）：幂等键  
- `qrcodeFileID`（string，可选）：房间小程序码的云文件 ID  

### 3. roomMembers 集合字段（建议）

- `roomId`（string）  
- `userId`（string）：微信 openid  
- `role`（string）：`GOD` / `PLAYER`  
- `nickName`（string）：如「玩家1」「玩家2」  
- `avatarUrl`（string，可选）  
- `avatarColor`（string）：随机分配的头像色值，如 `#5EC159`  
- `joinedAt`（number）  
- `playerIndex`（number）：1、2、3…  

### 4. 权限设置（建议）

- **rooms**：仅创建者可读；写可由云函数代劳（推荐「仅管理端可写」或「仅云函数可写」）。  
- **roomMembers**：  
  - 若希望前端直接查成员列表：可设为「所有用户可读，仅创建者可写」或「仅登录用户可读本房间成员」。  
  - 若全部通过云函数读写：可设为「仅云函数可写、仅云函数可读」，前端不直接查库。

---

## 三、云存储

1. 打开 **云开发控制台 → 存储**。  
2. 云函数 `roomCreate` 会把生成的小程序码上传到 **默认根目录** 下的 `qrcodes/` 目录，例如：`qrcodes/1730123456789-123456.png`。  
3. 无需预先建文件夹，上传时会自动生成。  
4. 存储权限：建议「所有用户可读」，以便通过临时链接在 addPlayer 页展示小程序码图片。

---

## 四、云函数部署与配置

### 1. roomCreate（创建房间并生成小程序码）

- **路径**：`cloudfunctions/roomCreate/`  
- **依赖**：已包含 `wx-server-sdk`。  
- **生成小程序码**：云函数通过 **HTTP 接口** `POST https://api.weixin.qq.com/wxa/getwxacodeunlimit?access_token=ACCESS_TOKEN` 生成小程序码，**scene** 参数为 `rid=房间ID`（即 roomId）。  

**操作步骤：**

1. 云函数使用 **云调用** `wxacode.getUnlimited` 生成小程序码，**无需配置 APP_SECRET**（云开发环境自动鉴权）。  
2. 若在体验版/开发版测试，可在云函数配置中可选添加环境变量 **QR_ENV_VERSION**=`trial` 或 `develop`（默认 `release`）。  
   注意：页面需先提交体验版/正式版后，生成的小程序码才能扫码进入。  
2. `cloudfunctions/roomCreate/config.json` 需包含 `"openapi": ["wxacode.getUnlimited"]` 权限。  
3. 在微信开发者工具中右键 `roomCreate` 文件夹，选择「上传并部署：云端安装依赖」。  
4. 在 **云开发控制台 → 云函数** 中确认 `roomCreate` 已部署且无报错。  

**说明**：  
- 该云函数会：创建房间记录、写入创建者到 `roomMembers`、用 access_token 调用 `getwxacodeunlimit` 生成小程序码（scene 为 `rid=roomId`）、将图片上传到云存储并把 `fileID` 写回 `rooms.qrcodeFileID`。  
- 小程序码的 **scene** 为 `rid=房间ID`，**page** 为 `pages/main-pages/addPlayer/index`，扫码会打开 addPlayer 并携带 scene。

---

### 2. roomJoin（扫码加入房间）

- **路径**：`cloudfunctions/roomJoin/`  
- **作用**：根据 `roomId` 将当前用户加入房间，分配 `playerIndex`（玩家 k）和随机 `avatarColor`，写入 `roomMembers`。  

**操作步骤：**

1. 在 `cloudfunctions/roomJoin/` 下执行 `npm install`（或使用开发者工具「云端安装依赖」）。  
2. 右键 `roomJoin` →「上传并部署：云端安装依赖」。  
3. 在云开发控制台确认部署成功。

---

### 3. getAddPlayerData（获取 addPlayer 页数据）

- **路径**：`cloudfunctions/getAddPlayerData/`  
- **作用**：根据 `roomId` 返回该房间的 `qrcodeFileID` 和成员列表（含 `isMe` 标记），供 addPlayer 页展示二维码与圆周成员。  

**操作步骤：**

1. 在 `cloudfunctions/getAddPlayerData/` 下安装依赖并上传部署（同上）。  
2. 在云开发控制台确认部署成功。

---

### 4. regenerateRoomQrcode（补生成房间小程序码）

- **路径**：`cloudfunctions/regenerateRoomQrcode/`  
- **作用**：为已有房间补生成小程序码。用于此前未配置 APP_SECRET 时创建的房间，或 roomCreate 生成失败时的补救。addPlayer 页在加载时若发现无二维码会主动调用此云函数尝试补生成。  

**操作步骤：**

1. 使用云调用，无需配置 APP_SECRET。若需生成体验版/开发版码，可配置 **QR_ENV_VERSION**=`trial` 或 `develop`。  
2. 右键 `regenerateRoomQrcode` →「上传并部署：云端安装依赖」。  
3. 在云开发控制台确认部署成功。

---

## 五、小程序端配置

1. **app.json**  
   - 已增加 `pages/main-pages/aaa/index` 和 `pages/main-pages/addPlayer/index`，无需再改（若你删过请加回）。  

2. **云开发初始化**  
   - 在 `app.js` 中确保已执行：  
     `wx.cloud.init({ env: '你的云环境ID' })`  
   - 若使用「当前默认环境」，可不写 env 或与云开发控制台一致。  

3. **扫码进入 addPlayer**  
   - 用户扫码后，会打开 `pages/main-pages/addPlayer/index?scene=xxx`。  
   - 页面在 `onLoad` 中从 `options.scene` 解析出 `rid=roomId`，再调用 `roomJoin` 加入房间，然后调用 `getAddPlayerData` 拉取二维码与成员列表并展示。

---

## 六、自测流程简要

1. 打开 **aaa** 页，点击「创建房间并去添加成员」。  
2. 应跳转到 **addPlayer**，并看到房间号、中央小程序码、圆周成员（创建者为「玩家1（我）」）。  
3. 使用另一部手机或模拟器扫码 addPlayer 中的小程序码，应能进入同一房间，并显示为「玩家2（我）」及随机颜色头像。  
4. 在云开发控制台 **数据库** 中查看 `rooms`、`roomMembers` 是否有对应记录；**存储** 中是否有 `qrcodes/xxx.png`。

---

## 七、常见问题

- **创建房间失败**：检查云函数是否部署、env 是否一致、数据库权限是否允许云函数写入。  
- **小程序码不显示**：使用云调用无需 APP_SECRET；检查 `config.json` 是否含 `wxacode.getUnlimited` 权限；确保 `pages/main-pages/addPlayer/index` 已存在于已提交的体验版/正式版；在 addPlayer 页点击「重试」可触发 `regenerateRoomQrcode` 补生成；检查是否成功上传到云存储并写回 `qrcodeFileID`。  
- **扫码后无法加入**：确认 `options.scene` 解析正确（`rid=roomId`），且 `roomJoin` 已部署且数据库允许写入 `roomMembers`。  
- **getwxacodeunlimit 报错**：确认 addPlayer 页面已提交到体验版或正式版；检查云函数 config.json 中 `wxacode.getUnlimited` 权限；体验版测试时可配置 QR_ENV_VERSION=`trial`。

完成以上步骤后，aaa 页即可拿到 roomId 并跳转 addPlayer，用户可通过微信扫码加入房间并获取随机颜色头像与玩家 k 名称。
