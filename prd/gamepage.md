
在游戏流程中，需要新增一个“出牌页面”，用于展示当前轮次的出牌内容，并让其他玩家对当前出牌玩家进行 0～5 分打分。
当且仅当 所有玩家完成打分 后，页面底部的 “开始表态” 按钮才可点击；若仍有玩家未完成打分，则按钮保持置灰不可点击。
本页面目标是：
清晰展示当前出牌玩家及出牌内容
支持其他玩家快速完成评分
保证评分流程完整后再进入下一步“表态”流程
2. 页面结构
页面整体分为 3 个区域：
2.1 顶部玩家列表区
位置：页面上方
组件来源：调用 components:user-list
用途：
展示当前房间所有玩家头像列表
高亮当前出牌玩家
可展示玩家当前状态（如是否已完成评分，具体表现可由组件能力决定）
2.2 中部出牌展示区
位置：页面中间大面积展示区域
样式：灰色背景容器
内容：插入图片 aaatest.png
用途：展示当前玩家本轮出的牌 / 内容
2.3 底部评分与操作区
位置：页面底部
包含内容：
当前出牌玩家信息文案
评分完成进度
0～5 分评分按钮
“开始表态”主按钮
3. 功能需求
3.1 玩家列表展示
功能描述
页面顶部调用 components:user-list 组件，展示所有玩家头像。
需求说明
必须接入 components:user-list
当前出牌玩家需要有明显高亮态
若组件支持，可同步展示：
已完成评分玩家状态
未完成评分玩家状态
展示规则
玩家头像按房间固定顺序展示
当前出牌玩家头像高亮
非当前出牌玩家正常展示
3.2 出牌内容展示
功能描述
在页面中部灰底区域展示当前出牌内容图片。
需求说明
灰底容器内插入图片资源：aaatest.png
图片应完整展示，避免拉伸变形
建议图片在容器内居中显示
图片加载失败时需有兜底：
展示默认占位图，或
展示“图片加载失败”提示
样式建议
容器为大尺寸圆角矩形
图片居中，适配不同屏幕尺寸
3.3 打分功能
功能描述
页面底部提供 0～5 分打分按钮，供玩家对当前出牌玩家进行评分。
评分范围
0 分
1 分
2 分
3 分
4 分
5 分
需求说明
每个分值为一个独立按钮
当前用户仅可提交 1 次有效评分
已选择的分值按钮需要有选中态高亮
点击某个分值后，记录当前用户对当前出牌玩家的评分结果
交互规则

用户点击某个分值按钮后：
当前分值高亮
评分结果立即保存（若产品需要可改为点击后自动提交）
允许修改：
在所有人评分完成前，可重新选择分值并覆盖原评分
3.4 评分进度展示
底部需要展示当前评分完成进度，例如：
完成打分人数：4/6
需求说明
分母为当前应参与评分的总玩家数
分子为已完成评分的玩家数
进度数据需实时更新

不参与自评
应评分人数 = 房间总人数 - 1
3.5 “开始表态”按钮状态控制
功能描述
底部主按钮文案为：开始表态
状态规则
未完成全员评分时
按钮置灰
不可点击

不触发任何跳转或流程推进

全员完成评分后

按钮高亮可点击

点击后进入下一流程：“表态”阶段

判定逻辑

只有当 所有应评分玩家都完成打分 后，按钮才可点击。

可表示为：

if 已评分人数 == 应评分人数 => 按钮可点击
else => 按钮置灰不可点击

4. 交互流程
4.1 页面进入

进入出牌页面

顶部展示玩家列表

中部展示 aaatest.png

底部展示评分区与“开始表态”按钮

初始状态下：

若当前未全员评分，则“开始表态”按钮置灰

4.2 用户评分

用户点击 0～5 分中的任一分值

前端更新选中态

提交评分结果

页面更新“完成打分人数”

4.3 全员评分完成

当最后一名应评分玩家完成打分

系统将“开始表态”按钮切为可点击状态

4.4 进入表态阶段

用户点击“开始表态”

跳转/进入“表态”流程页面
