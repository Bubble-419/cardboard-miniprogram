# 谁是卧底词组清单

当前代码包含 **36 个词条、18 个对比组、32 对可抽取词组**。开局从 32 对中随机抽取一对，再随机决定哪一个词给平民、哪一个词给卧底，因此下表的 A、B 不固定对应身份。

本清单供内容核对与老师审阅，保留现有用词和释义，不代表词组质量或文案已完成确认。核对日期：2026-10-11。实际对局以服务端代码为准；修改词库时同步更新本清单。

## 词条与现有释义

下列编号及分类按客户端牌库的展示顺序排列，释义原样取自现有词库。

### 点击类

| 牌库编号 | 对局用词 | 现有释义 |
| --- | --- | --- |
| 01 | 开关 | 控件 0/1 状态直接对应物件状态，状态不变则物件不变，不关心动作过程。 |
| 02 | 单击 | 需完成按下再抬起（0→1→0）才触发一次，不留存状态，抬起时生效。 |
| 03 | 按下 | 捕捉从 0→1 的瞬时变化即触发，不要求抬起，也不留存状态。 |
| 04 | 持续触发 | 按住即开始，以固定间隔匀速连发，无延时门槛。 |
| 05 | 长按 | 按住超过时间阈值才触发一次，不连发，用延迟降低误触。 |
| 06 | 双击 | 在时间窗口内完成两次 0→1→0 变化才触发，靠节奏区分于单击，不留存状态。 |
| 07 | 多点开关 | 多个二元控件须同时处于状态1，物件才对应目标状态，强调组合成立的绝对映射。 |
| 08 | 多点有序点击 | 按预设先后顺序点击多个点位即可，不强调点位相对方位。 |
| 09 | 多点同时点击 | 多个点位须在时间容差内同时完成变化，强调同步性，不强调点位顺序或方位。 |

## 内容核对事项

- **“晃动”与“震动”命名不一致。** 对局词条和 `ixdl-31` 使用“晃动”，牌库显示“晃动/震动”，仓库图片文件名使用“震动”。发言页直接把对局用词传入 `getWordCardAssets`，该函数按原词拼接文件名，未处理此别名，因此会请求“晃动3x.webp”和“晃动13x.webp”。仓库没有这两个文件；云端是否另有同名资源尚未核对。
- **分类口径有差异。** “轻扫切换”在词条源码注释中归于“位移类：单点”，在牌库中归于“多维协同”。本清单采用牌库分类，词对保持原样。
- **释义与词对仍待内容确认。** 本次仅整理现有内容，未改写说明、删减词语或重新配对。后续内容确认应覆盖术语命名、释义长度及每对词的可区分性。

## 维护方式

确认词组后，同步修改服务端和客户端的 `WORD_ENTRIES/PAIR_GROUPS`，核对牌库分类及两张卡片资源，并更新本清单。对局词库被打包进云函数；修改后需重新构建，云端发布按[部署说明](ROOM_PROTOCOL_V3_DEPLOYMENT.md)执行。
