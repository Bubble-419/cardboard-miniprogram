# 测试问题修改清单

> 来源：测试反馈整理（2026-08）  
> 组织原则：按用户路径 → 页面 → 条目；跨页问题单独成章；每条标注类型与优先级。

## 优先级定义

| 优先级 | 含义 | 处理原则 |
|--------|------|----------|
| **P0** | 阻断 / 数据错误 / 主链路不可用 | 立刻修；阻塞发版 |
| **P1** | 主流程不顺、关键交互错误、权限错误 | 本迭代内修完 |
| **P2** | UI / 文案 / 体验增强 / 待确认需求 | 可排后续；不阻塞主链路 |

**类型说明**

- **Bug**：行为错误或与预期相反
- **UI**：视觉 / 文案 / 布局
- **功能**：新增或调整能力
- **交互**：操作手感 / 编辑态等细节

| 优先级 | 类型 | 条目 | 验收要点 |
|--------|------|------|----------|
| P0 | Bug | 头像刷新不出 / 消失 | 进房、切页、同步后头像稳定，不偶发空白 |
| P1 | Bug | 全局头像列表被内容滚动带走 | 顶栏头像列表固定，页面滚动时位置不变 |

### 0.3 导航返回栈（全局审查）

| 优先级 | 类型 | 条目 | 验收要点 |

| P0 | Bug | 「上一页 / 返回」几乎都会退两级 | **全站审查**返回实现（`navigateBack` 层数、错误叠 `navigateTo`、双绑返回等）；每页点返回只退一层到正确上一页。`brainstormMode` → `addPlayer` 为典型验收点之一，非唯一 |

### 0.4 固定页禁滚（全局策略）

| 优先级 | 类型 | 条目 | 验收要点 |

1. 全局：图片上云不显示 / 部分手机头像不显示 / 德心说明图不显示

6. 房间：房主退出后成员一直加载中  
7. 对局：打分反复点击横跳  
8. 表态：跳轮次  
9. 德心：返回房间应退出当前脑暴模式

### P1（主流程与关键交互）

1. 全局：头像列表固定不可被滚走；固定页禁滚策略  
2. 首页：历史工作坊保存  
3. 房间：自动跳转；踢人拖到区域  
4. 情境：滚动 + 加号  
5. 提交/选择设计问题：点情境进确认；编辑态位置/同步/光标  
6. 选玩家：禁滚；确认按钮出现更快  
7. 对局：纪要卡可见；只留灵感入口；创意点复盘输入/拍照/权限  
8. 表态：房主看已表态人数  
9. 结束页：接入已有 leaderboard；全员可回房间  
10. 灵感：限制上传 1 张  
11. 德心：说明书禁滚  
12. 卧底：翻开多字；平票提示与投票页展示；弃票；出局者可见在场玩家  

### P2（体验与增强）

1. 头像框倒计时 / 小三角 / 动效
