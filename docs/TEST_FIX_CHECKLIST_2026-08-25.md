# 测试问题修改清单（第二批）

> 来源：测试反馈整理（2026-08-25）  
> 组织原则：按用户路径 → 页面 → 条目；跨页问题单独成章；每条标注类型与优先级。  
> 冲突策略（若合入 visual）：**功能逻辑保留 april；视觉样式保留 visual**。

## 优先级定义

| 优先级 | 含义 | 处理原则 |
|--------|------|----------|
| **P0** | 阻断 / 数据错误 / 主链路不可用 | 立刻修；阻塞发版 |
| **P1** | 主流程不顺、关键交互错误、权限错误 | 本迭代内修完 |
| **P2** | UI / 文案 / 体验增强 / 待确认需求 | 可排后续；不阻塞主链路 |

**类型说明**

- **Bug**：行为错误或与预期相反
- **UI**：视觉 / 文案 / 布局
- **功能**：新增或调整能力
- **交互**：操作手感 / 编辑态等细节
- **核查**：声称已修，需代码确认 + 真机验收；未修则升为同级 Bug
